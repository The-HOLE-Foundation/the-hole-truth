# v0 corpus & flow scope

**Owner:** CTO
**Status:** committed for v0; revisit on Hire 3 (Legal Domain Expert) onboarding.
**Last updated:** 2026-06-01

THE-4 requires federal FOIA + all 5 priority states (TX PIA, CA CPRA, NY FOIL, IL FOIA, FL Sunshine). The v0 corpus ships **all 6 jurisdictions**, with interpretive uncertainty handled at the field level (per-field `certainty: needs_escalation` plus `corpus_meta.open_questions`) rather than by deferring entire jurisdictions. This honors the CEO's direction: *"Do not invent — when a statute is ambiguous, mark the field uncertain and escalate to me."*

An earlier revision of this doc proposed deferring CA and FL to v0.5 because of interpretive overhead. That deferral was not approved by the CEO and is superseded — the field-level escalation pattern lets us ship the breadth the ticket requires while preserving the correctness bar.

## Record types — picks

For each record type below, the request template must be valid across all four v0 jurisdictions. We pick categories with the cleanest exemption profile.

| Record type | Status | Reason |
| --- | --- | --- |
| **Agency emails (custodian + topic + date range)** | **In v0** | Universally a "record" under every transparency statute. Standard Exemption-5/deliberative-process and personal-privacy carveouts apply; both are uniform across federal and the three v0 states. |
| **Government contracts and procurement records** | **In v0** | Public-financial records are the least-exempt category in every v0 jurisdiction. Strong public-interest hook for fee waivers. |
| **Meeting minutes and agendas of public bodies** | **In v0** | Required to be kept and publicly available under every v0 jurisdiction's open-meetings law. Very few exemptions. Good "easy win" category for first-time requesters. |
| **Police body-worn camera footage** | **Deferred to v0.5** | Variance across jurisdictions is enormous: CA Penal Code § 832.7 + SB 1421/SB 16; NY post-§ 50-a repeal regime; TX Code Crim. Proc. art. 2.139 + Occupations Code § 1701.661; IL Law Enforcement Officer-Worn Body Camera Act. Each has its own production deadline, redaction obligations, and victim-notice requirements. High risk of producing a wrong citation in v0. |
| **Email retention / records-management policies** | **Backlog** | Useful diagnostic category for "did the agency preserve what I'm asking about" but not a typical first request. Defer. |

**Net:** 3 record types for v0. Meets the 3–5 bar.

## How the picks change the v0 flow

The user picks: **(1) jurisdiction**, **(2) record type**, **(3) the records they want** (free text), **(4) optional purpose statement**.

The system assembles a request that:

1. Names the correct controlling statute from the jurisdiction record.
2. Cites the correct response deadline and constructive-denial provision.
3. Includes the correct fee-waiver language for the chosen requester category (if specified).
4. Routes to the correct submission method (email > online portal > mail; preferred order is per-jurisdiction).
5. Includes a citation footnote block that links to every fact's source URL — the user can verify before sending.

**Critical constraint:** the citation is **not** generated by an LLM. It is pulled deterministically from the corpus. LLMs are used (in later v0 work) only to render plain-language explainers and to polish the user's records description — never to write the legal claim.

## Open escalations to the CEO and (future) Legal Domain Expert

- TX PIA `business_days` definition counts days the agency is "open to the public for the conduct of official business" — confirm we're applying that correctly for state-holiday handling.
- NY FOIL § 89(3)(a) allows agencies to certify a 20-business-day extension; we need to decide whether v0 surfaces that contingency to the user or assumes the default.
- IL FOIA distinguishes between "commercial" and non-commercial requesters with different deadlines (21 vs. 5 business days). The user picker must default to non-commercial with an opt-in for commercial.
